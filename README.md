# IoT-Based Smart Dengue Environmental Risk Monitoring and Early Warning System

## 📌 Project Overview

This project aims to develop a low-cost IoT-based system for monitoring environmental conditions associated with dengue risk.

The system uses an ESP32-based monitoring device to collect environmental parameters such as:

- Temperature
- Humidity
- Rainfall
- Stagnant-water depth

  ## 🎯 Aim
To develop a low-cost IoT-based system for real-time monitoring of environmental conditions associated with dengue risk and generation of an early-warning risk indicator.
